NOTES BEFORE STARTING
- Log file:  <DS2 install>\ds2_seamless_coop.log (truncated each launch)
- The H26 instrumentation logs EVERY protobuf message:
    [H26 >>] <classname>   = outgoing
    [H26 <<] <classname>   = incoming
- Soapstone-place is expected to send class name containing
  "Sign" or "Summon" (e.g. RequestSummonSign, opcode 0x039B per
  SESSION_LOG_2026_03_17.md).
- If you don't see ANY [H26 >>] line when you click to place, the
  game refused to send — local offline-mode check is the culprit.
- If you see [H26 >>] but no [H26 <<] response, server-side.

CHARACTER STATE
- Throwaway character per H-04. Level 1-15ish.
- Have White Sign Soapstone in inventory (overlay "Grant Soapstones"
  button, or use a character that already has it).
- Be HUMAN (not hollow) if possible. Sign placement may require
  effigy use first.
- Be in a sign-placement area — outside Majula bonfire, NEAR the
  bonfire (a few steps away from the flame itself), works. Avoid
  boss-locked areas.
